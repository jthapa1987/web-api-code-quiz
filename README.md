# ⚡ JavaScript Code Quiz  
![Quiz Logo](https://img.shields.io/badge/JS%20Code%20Quiz-2.0-ffcc00?style=for-the-badge&logo=javascript&logoColor=black)
![Author](https://img.shields.io/badge/Author-Jeevan%20Thapa-007bff?style=for-the-badge)

A fast, fun, and timed JavaScript quiz designed to test your fundamentals — complete with a countdown timer, multiple‑choice questions, and high‑score saving using `localStorage`.

---

## 🚀 Live Demo  
Try the quiz here:  
👉 **https://jthapa1987.github.io/web-api-code-quiz/**

---

## 🧠 Features  
- ⏱️ **Start button triggers timer**  
- ❓ **Multiple‑choice questions**  
- ⚠️ **Wrong answers subtract time**  
- 🏁 **Quiz ends when time hits 0 or questions finish**  
- 💾 **Save initials + score to localStorage**  
- 🏆 **High‑score leaderboard included**
